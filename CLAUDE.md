# CLAUDE.md

Guidance for working in this repository.

## What this is

An FPGA **FM-radio receiver** experiment for the **Digilent Zybo Z7-20** board, built with **Xilinx Vivado 2022.1**. HDL is **Verilog**. The design currently generates the local-oscillator / station clocks and a PWM signal, driven out on the Pmod JE header for measurement.

- Target part: `xc7z020clg400-1`
- Board part: `digilentinc.com:zybo-z7-20:part0:1.1`
- Top module: `LO`

## Layout

This is a standard Vivado project directory. Only a few paths hold hand-written source — everything else is generated by Vivado and should not be edited by hand.

| Path | What it is |
|------|------------|
| `zybo-fm-radio.xpr` | Vivado project file (open this in Vivado). |
| `zybo-fm-radio.srcs/sources_1/new/` | **Hand-written Verilog sources.** Add new modules here. |
| `zybo-fm-radio.srcs/constrs_1/imports/digilent_constraints/Zybo-Z7-Master.xdc` | The pin/clock constraints file. Uncomment the ports you use. |
| `zybo-fm-radio.gen/`, `zybo-fm-radio.cache/`, `zybo-fm-radio.runs/`, `zybo-fm-radio.ip_user_files/`, `zybo-fm-radio.hw/` | **Generated by Vivado** (IP, synthesis/impl runs, caches). Do not edit; regenerate from Vivado instead. |

## Existing modules

- `LO.v` — top module `LO`. Buffers `sysclk` (125 MHz, pin K17) through an `IBUFG`, instantiates two Clocking Wizard IP cores (`clk_wiz_0`, `clk_station`) to synthesize carrier/station clocks, and a small `pwm` module. Outputs go to the Pmod JE pins (`je[3:1]`).
- `pwm` (also in `LO.v`) — simple 8-bit free-running counter PWM; `pwm_out` high while `counter < duty`.
- IP cores `clk_wiz_0` and `clk_station` are MMCM-based Clocking Wizards (managed by Vivado, regenerated from `.xci`).

## Board resources (from the XDC)

Common ports are present in the master XDC but **commented out by default** — uncomment the lines for the signals you instantiate, and make the top-module port names match exactly.

- `sysclk` — 125 MHz system clock, pin K17 (active).
- `led[3:0]` — 4 user LEDs (M14, M15, G14, D18).
- `btn[3:0]` — 4 push buttons (K18, P16, K19, Y16).
- `sw[3:0]` — 4 slide switches (G15, P15, W13, T16).
- `je[7:0]` — Pmod JE header, used here for scope probing.

## Conventions

- Add new hand-written Verilog under `zybo-fm-radio.srcs/sources_1/new/`, one module concern per file where practical.
- **When you create a new `.v` file, also register it in `zybo-fm-radio.xpr`** so Vivado picks it up. Add a `<File>` entry inside the `sources_1` `<FileSet>` (next to the existing `LO.v` entry), e.g.:

  ```xml
  <File Path="$PSRCDIR/sources_1/new/your_module.v">
    <FileInfo>
      <Attr Name="UsedIn" Val="synthesis"/>
      <Attr Name="UsedIn" Val="implementation"/>
      <Attr Name="UsedIn" Val="simulation"/>
    </FileInfo>
  </File>
  ```
- When adding I/O, uncomment the matching ports in the master XDC; vector port names must match the constraint names (e.g. `led[0]`).
- Use synchronous logic clocked off a buffered/derived clock; this is a `posedge`-clocked design.
- This project is edited and built through the Vivado GUI/toolchain on Windows — there is no command-line build script checked in. Treat `.gen`/`.runs`/`.cache` as disposable build output.
